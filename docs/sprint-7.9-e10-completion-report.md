### 2.3 Phase 3 — Data Governance Enforcement
Enforced five automated governance gates implemented in the Stetho backend:
1. **Cryptographic Deduplication:** Real-time SHA-256 digest computation; immediate HTTP 409 rejection on duplicate content.
2. **Signal Quality Gating:** Mandatory check for $f_s \ge 16\text{ kHz}$, clipping $\le 0.1\%$, and RMS energy $> -60\text{ dBFS}$.
3. **Calibration Role Isolation Guard:** API-enforced rule requiring ground truth to be confirmed `HEALTHY` with multi-modal physical inspection evidence before assignment to `CALIBRATION_ENROLLMENT`.
4. **Sealed Evaluation Immutability:** Evaluation manifests are cryptographically sealed with a cumulative SHA-256 manifest hash, making them permanently read-only prior to computing out-of-domain benchmark metrics.
5. **Traceable Ground-Truth Revision History:** Database tracking of prior status, new status, timestamp, user ID, and written justification for all ground-truth updates in `annotation_revisions`.
