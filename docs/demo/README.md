# Stetho — Demo Resources & Runbooks

This directory contains resources, runbooks, and fallback audio manifests for the Stetho acoustic inspection assistant.

## Demo Tracks

1. **Live Track:** Physical demo fan audio recording and analysis via live microphone stream/file upload.
2. **Fallback Track:** Prerecorded baseline and anomalous fan audio clips stored for deterministic verification when audio hardware is unavailable.
